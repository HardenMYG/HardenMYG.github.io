# HardenMYG.github.io

GitHub Pages personal site for `HardenMYG`.

## Preview

Open `index.html` in a browser.

## Publish

1. Create a public GitHub repository named `HardenMYG.github.io`.
2. Push these files to the repository's default branch.
3. Open `https://HardenMYG.github.io` after GitHub Pages finishes deploying.

## Customize

- Replace `hello@example.com` in `index.html` with your email.
- Edit the About and Stack sections in `index.html`.
- Change colors and layout in `styles.css`.
